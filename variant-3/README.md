# Save the Date — red design, version 3

This folder contains the third design option. It uses the supplied red card artwork, keeps the design in place, and adds a live countdown in the open space below “Save the date” and above the printed unit labels. The numbers sit directly on the card texture without added boxes.

The date and time zone are shared with the main site through `../event-config.js`: June 17, 2028, in `America/Vancouver`. The countdown runs to midnight at the start of that date.

## Publish this option

Upload the whole `variant-3` folder to the top level of the `Birdlia/save-the-date` repository. Keep the folder name and the `assets` subfolder. Then open:

https://birdlia.github.io/save-the-date/variant-3/
